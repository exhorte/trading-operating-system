# Phase Start Command

Use this command when beginning a new development phase.

## Required Procedure

1. Read:
   - `CLAUDE.md`
   - `.claude/CLAUDE.md`
   - `context/README.md`
   - `context/project/development_manifesto.md`
   - `context/project/project_state.md`
   - the current phase file in `context/project/phases/`
2. Identify the current `Next Up` item.
3. Read only the context files relevant to that phase.
4. Produce:
   - understanding summary
   - impact analysis
   - technical design document
   - implementation checklist
   - validation questions if necessary
5. Do not modify product code until the user validates the design, unless the user explicitly asked for direct implementation.

## Required Output Shape

- Objective
- Existing Context
- Impact Analysis
- Proposed Architecture
- Data Flow
- Files To Create Or Modify
- Risks
- Acceptance Criteria
- Implementation Checklist
