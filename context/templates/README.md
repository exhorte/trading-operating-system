## Visual References

The image files in this directory are inspiration references for the dashboard, trade journal, and replay workspace.

They must be used as product inspiration, not copied literally.

Do not copy:

- TradeZella branding
- exact layout measurements
- proprietary illustrations
- trademarked labels
- exact visual identity

Extract reusable patterns instead:

- dark trading cockpit
- dense metrics
- left navigation
- top command bar
- P&L calendar
- trade table
- replay/chart workspace
- status chips and tags
